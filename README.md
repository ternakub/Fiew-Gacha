# Fiew-Gacha

เว็บไซต์กล่องสุ่ม FIEW แบบ Static Site พร้อมการ์ด 30 ใบ

## ทดลองบนเครื่อง

```bash
python -m http.server 8000
```

เปิด `http://localhost:8000` ในเบราว์เซอร์

## ขึ้น Render แบบฟรี

เชื่อมโฟลเดอร์นี้กับ GitHub แล้วสร้าง Blueprint จากไฟล์ `render.yaml`
ระบบจะสร้าง Static Site ชื่อ **Fiew-Gacha** โดยใช้แผน Free

## ระบบที่รวมไว้

- คำถาม 12 ข้อ ใช้ตามลำดับครั้งละ 3 ข้อ แล้ววนกลับข้อ 1–3
- คำตอบไม่มีผลต่อผลสุ่ม
- โหลดภาพการ์ดไว้เบื้องหลังหลังจากกดเริ่ม
- เรต 1–5 ดาวและ Joker: 34%, 30%, 20%, 10%, 5%, 1%
- อนิเมชันหีบหด–ขยาย 3.5 วินาทีก่อนเปิด
- เพลงพื้นหลัง ปุ่มเปิด/ปิดเสียง และเสียงเปิดหีบ
- สุ่มใหม่ต้องตอบคำถามใหม่
- ดาวน์โหลด JPG พร้อมชื่อการ์ดภาษาไทย
